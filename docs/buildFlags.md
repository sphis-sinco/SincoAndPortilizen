# SAVESLOT_SUFFIX=
`SAVESLOT_SUFFIX=sphis` will set the saveslot suffix to "sphis" instead of whatever it defaults to.

# DISABLE_ANNOYING_ERRORS
Disables the popups on the `FlxG` console when an error is logged

# DISABLE_ANNOYING_WARNINGS
Disables the popups on the `FlxG` console when a warning is logged
